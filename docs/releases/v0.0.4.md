# FilePreview v0.0.4

## 新功能

- 新增 PDF 逐页预览，支持在预览区滚动查看文档。
- 支持通过 LibreOffice 本地转换预览 `.doc`、`.docx`、`.ppt`、`.pptx`、`.xls` 和 `.xlsx`。
- 未安装 LibreOffice 时，Windows 可在应用内使用 winget 快速安装，也可跳转官网下载并重新检测。

## 优化与修复

- Office 文件统一转换为 PDF 预览，提升复杂文档的兼容性。
- 移除旧的 DOCX HTML 和 PPTX 文本提取预览实现。
- 新增 Windows 本地签名打包脚本，统一使用项目更新私钥生成安装包和更新签名。
